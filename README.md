# MecaniQA Automotive Tech

## Programa de Trainee 2026.2

### Equipe Porto Velho

## Contexto

A MecâniQA Tech é uma startup que fornece um sistema SaaS de gestão e diagnóstico automotivo para oficinas mecânicas. A aplicação utiliza Java, MySQL e Redis, porém a infraestrutura atual apresenta dificuldades de escalabilidade e esgotamento frequente de recursos.

Nesta atividade, a equipe atua como Engenheiros Cloud/DevOps, com o objetivo de desenvolver uma infraestrutura mais resiliente e conteinerizada, utilizando Docker, Docker Compose, Terraform e Kubernetes.
